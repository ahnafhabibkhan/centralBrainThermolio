# Thermolio interface reference

The internal workspace uses the Thermolio wordmark from the [official logo asset](https://thermolio.com/cdn/shop/files/Thermolio_Logo_Black_LONG_trimmed_2.svg). A local copy is served with the application so sign-in does not require third-party asset requests.

The supplied platform-page HTML and [Thermolio platform page](https://thermolio.com/pages/platform) informed the visual design. The interface uses Thermolio green `#27ae60`, charcoal `#09090b`, muted text `#52525b`, white panels, fine borders, and a subtle 40-pixel grid. Dark green `#0f5e34` provides readable small text on white backgrounds. Typography uses locally available sans-serif and monospace fonts without loading remote font services.

The site is a visual reference. The internal application does not include its sales forms, marketing claims, tracking scripts, or external calls to action. Authentication and approval controls remain required for workspace data.
